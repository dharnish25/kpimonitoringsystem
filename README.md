# Ila KPI Monitoring System

A ReactJS dashboard for monitoring key performance indicators with live updates. Each KPI is shown with a visual status indicator, a progress bar against its target, a sparkline, and a comparison against yesterday or last week. Threshold alerts fire the moment a KPI crosses a warning or critical level.

## Features

- **Live KPI cards** – six KPIs (revenue, customer satisfaction, order fulfillment, active users, API response time, error rate) refresh every few seconds from `GET /api/kpis/live`.
- **Visual indicators** – status badges (On track / Warning / Critical), a progress bar with target and threshold markers, and a sparkline of recent readings.
- **Chart section** – a live trend chart with target and threshold lines, plus a 24-hour vs. previous-24-hour comparison chart for the selected KPI.
- **Threshold alerts (bonus)** – editable warning/critical levels per KPI (saved in the browser), with an alert feed that records breaches and recoveries.
- **Historical comparison (bonus)** – a table comparing every KPI now vs. the same time yesterday and one week ago.
- **Controls** – pause/resume the live feed, change the refresh interval, and switch the comparison baseline.

## Syllabus mapping

| Topic | Where |
|-------|-------|
| State management | `src/store/kpiStore.ts` (TanStack Store: KPIs, history, thresholds, alerts, UI state) |
| Charts | `src/components/ChartSection.tsx` (Chart.js via react-chartjs-2), `Sparkline.tsx` |
| Conditional rendering | Loading skeleton, error/retry state, status badges, alert empty state, live/paused indicator |
| Real-time updates | `src/hooks/useLiveKpis.ts` polls `GET /api/kpis/live` |

## Folder structure

```
src/
├── components/     KpiCard, ProgressBar, ChartSection, AlertsPanel, ComparisonTable, StatusBadge, Sparkline
├── pages/          Dashboard
├── hooks/          useLiveKpis (fetching + polling)
├── store/          kpiStore (global state + actions)
├── lib/kpis.ts     KPI catalog, signal generator, status & formatting helpers
└── routes/
    ├── index.tsx           → renders the Dashboard
    └── api/kpis/
        ├── index.ts        → GET /api/kpis
        └── live.ts         → GET /api/kpis/live
```

Component structure: `Dashboard → KpiCard → ChartSection` (selecting a card drives the chart section).

## API

| Endpoint | Returns |
|----------|---------|
| `GET /api/kpis` | KPI definitions, current snapshot, recent history, and hourly 24h comparison data |
| `GET /api/kpis/live` | The latest reading for every KPI, with the values from 24h and 7 days earlier |

KPI readings are generated by a deterministic, time-based simulator (`src/lib/kpis.ts`), including occasional "incidents" so alerts can be seen in action. Replacing `sampleValue()` with real data sources is the only change needed to connect live business data.

## Tech stack

React 19, TanStack Start/Router, TanStack Store, Chart.js + react-chartjs-2, Tailwind CSS 4, lucide-react icons, deployed on Netlify.
